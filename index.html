Silo for Kodi 21+

Your Silo library, made for the couch.

Kodi source

https://slimshizn.github.io/Silo-Theater/

Repository installer

repository.silo.theater-1.0.2.zip

Features

  • TV home screen

    Continue Watching, Next Up, For You, Calendar, Collections, filters.

  • Direct play or conversion

    Original files play directly; your server converts the rest. Quality picker included.

  • Skip intro, Up next

    Skip intros and credits, auto-play the next episode.

  • Subtitles and audio

    Follow your profile, remembered per show, online subtitle search.

  • Profiles

    Code sign-in, profile PINs, multiple servers.

  • Widgets

    Silo rows on Kodi's home screen with Founders Theater Widgets.

Install

  1. Settings → File manager → Add source: enter the address above.
  2. Add-ons → Install from zip file: select repository.silo.theater-1.0.2.zip.
  3. Install from repository → Founders Theater Repository: install Founders Theater.
  4. Open it, enter your server address and sign in.
