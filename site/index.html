Settle in. Set it up.

A Silo server and Kodi 21+ are required.

  1. Add the source

    In Kodi, open Settings → File manager → Add source. Enter the address above and name it Silo Theater.

  2. Install the repository

    Open Add-ons → Install from zip file → Silo Theater, then select repository.silo.theater-1.0.1.zip.

    If prompted, allow Unknown sources in Settings → System → Add-ons.

  3. Install Silo

    Choose Install from repository → Silo Theater Repository, find Silo and select Install.

  4. Make yourself at home

    Open Silo in Kodi. Enter your Silo server’s URL, sign in with a code or your username and password, and choose your profile.

An early test build

This build supports original-file HTTP direct play. Titles that need remuxing or transcoding may be refused. Playback compatibility still needs testing on your Kodi device.

HDR and Dolby Vision capabilities are configured manually. Select P7 FEL only on a device, firmware and Kodi build you have verified can play the full enhancement layer.
